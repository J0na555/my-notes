# my-notes

 This repository serves as my personal knowledge base and a living record of my intellectual growth a digital garden where I cultivate evolving ideas, technical documentation, and personal projects in one central space.
While my foundation is rooted in Computer Science, this site serves as the bridge between my formal studies and the niche interests I explore in my spare time. 
It is built using the excellent [Quartz](https://quartz.jzhao.xyz/) framework, authored entirely in [Obsidian](https://obsidian.md/), and deployed through GitHub Actions. Rather than a static portfolio, I treat this as a living ecosystem of ideas that grows as I do.
