## Spring Security Basics

### What is Spring Security?

Spring security is a framework that provides authentication, authorization  and protection against common security vulnerabilities

- by default, spring security secures all end points and requires authentication
- it supports multiple authentication mechanisms (in-memory, database, OAuth2, ..)
- it provides easy integration with [[JWT Overview|JWT]] for securing  REST APIs.
